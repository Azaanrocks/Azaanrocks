### `ColonEmoji` — emoji, right where you type

[A browser extension](https://github.com/Azaanrocks/ColonEmoji) that brings
Discord-style `:shortcode:` autocomplete and a searchable `::` picker to
websites. Has recents, custom Discord emoji, and builds for Chrome, Edge, Brave,
and Firefox.

### `Metro8.1-GamesApp-Android` — Xbox Games, the Windows Phone way

A [Kotlin + Jetpack Compose recreation](https://github.com/Azaanrocks/Metro8.1-GamesApp-Android)
of the Windows Phone 8.1 Xbox Games hub. Flat tiles, panorama scrolling, and
the Metro look—made for Android.

### `Freshathon-Project` — IMS chatbot concept

A [Freshathon 2.0 project](https://github.com/Azaanrocks/Freshathon-Project)
exploring a chat interface for college information: student queries, teacher
document uploads, Flask, SQLite, and local Ollama models. This one’s still a
work in progress.
